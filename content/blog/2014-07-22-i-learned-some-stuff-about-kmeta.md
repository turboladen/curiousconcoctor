I ran across this interesting article about Potassium Metabisulfate from winemakersacademy.com:
[http://winemakersacademy.com/potassium-metabisulfite-wine/](http://winemakersacademy.com/potassium-metabisulfite-wine/).
If you’re concocting/brewing and don’t know how the stuff works, it’s definitely worth a read. If
not, here’s my TL;DR.

- It’s an antioxidant, and antioxidants remove free oxygen in their environment.
- Since oxygen speeds up the aging process and KMeta removes free oxygen, it’s good for preventing
  spoiling (aka a preservative).
- Because it’s an antioxidant, it can be used as a sanitizer (which is what I use it for).
- Using KMeta to slow up a fermentation (as opposed to using for sanitization) will leave some
  residual potassium.
- After bonding with water, it forms, amongst other things,
  [SO2 (sulfur dioxide)](http://en.wikipedia.org/wiki/Sulfur_dioxide); SO2 is the reason you see
  “Contains Sulfites” on wine lables.
- KMeta takes time to bond with the oxygen in a must, so don’t drink it right after adding it.

Happy Concocting!
